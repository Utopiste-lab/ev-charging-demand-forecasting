# Member 3：初步模型实验

已完成 Caltech 的 Seasonal Naive 与 Ridge Regression 单小时滚动预测。结果来自实际运行，原始数据未修改；本阶段不包含其他模型、多时域或跨站点迁移。

## 可直接写入第二次进度汇报的简短分析

在 Caltech 的共同测试集（2020-07-15 至 2020-12-02，共 3,384 小时）上，Seasonal Naive 的 MAE/RMSE 为 0.2787/0.7131，优于 Ridge 的 0.6710/0.9908。Ridge 在非零小时上的 MAE 较低（0.9683 对 1.1413），但在占测试集 86.82% 的零值小时上误差更大，因此整体表现较差。Ridge 产生 1,233 个负预测值（36.44%，最低 −0.9147），本次不截断、不取整，并将其作为线性模型预测计数的局限记录。训练与测试的平均计数从 1.9006 降至 0.1785 次/小时，且长零值区间的观测完整性、源时间戳语义和异常峰值仍待核实，所以这些结果仅支持当前输入和时段下的初步比较。

## 数据质量与处理决定

| 站点 | 小时范围（输入时钟） | 小时数 | 零小时 | 会话总数 | ≥24h 零区间 | 最长零区间 |
|---|---|---:|---:|---:|---:|---:|
| Caltech | 2018-05-01 00:00—2020-12-02 23:00 | 22,728 | 13,379 | 31,860 | 53 | 287h |
| JPL | 2018-10-08 13:00—2020-12-02 23:00 | 18,875 | 12,575 | 27,723 | 44 | 550h |

- `hour` 初读为字符串，代码严格解析为时间；`session_starts` 是非负整数，`site` 为站点字符串。三个字段没有缺失值；没有重复的 site/hour 键；各站点小时网格连续，未自行补值。
- “没有缺失行”只说明 Member 2 的小时网格完整，不能证明每小时都有有效观测。未提供采集在线日志、缺失标记或完整性说明，零值原因无法识别；主实验保留全部零值，不插补，不以未来零区间筛除训练或测试样本。
- Caltech 最长零区间为 2020-07-19 18:00—2020-07-31 16:00。测试集中 1,015 个小时落在至少 24 小时的连续零区间内；该标记是事后诊断，绝不作为模型输入。
- Caltech 月会话总数从 2020-02 的 722 降至 04 月的 29、05 月的 15；数据表现出明显分布变化，无法单凭现有文件将其归因为真实需求变化或观测中断。逐月统计见 `monthly_quality_summary.csv`。
- 2018-12-06 06:00 有 193 次、2018-09-24 22:00 有 99 次的峰值。193 次对应 193 个不同文件路径，并非小时聚合重复；抽查原始记录还看到相同设备前缀的短间隔文件。不能据此认定为 193 辆独立车辆抵达，本次保留并披露，后续应核实会话拆分语义。
- CSV 无时区；原始时序抽查显示 `+00:00`，但没有完整来源说明，所以保留输入时钟，不擅自换算当地时区或修正夏令时。一个 JPL 样本的文件名时间与首个可见记录时间不同，因此 `session_start` 是现有阶段定义的会话开始代理量，不能视为已独立验证的实际到达时间。
- 首尾小时可能只覆盖部分观测时间，主实验也保留；目前的结果面向“已记录会话开始数”，不等同于能量需求或车辆到达真值。JPL 仅审计，留作后续实验。

## 实验设置与防泄漏

定义 `y[t]` 为区间 `[t,t+1h)` 开始的会话数量。在时刻 `t` 发出预测，假定 `[t−1h,t)` 的计数已及时到达：最新可用观测为 `y[t−1h]`，预测到区间结束的时域为 1 小时。例如在今天 10:00 预测今天 10:00–11:00，Seasonal Naive 取昨天 10:00–11:00 的计数，即 `y[t−24h]`；不是一次性提前预测整天。

Ridge 使用 34 个特征：小时独热编码（23 列）、星期独热编码（6 列）、是否周末、lag 1/24/168 小时，以及过去 24 个已完成小时的平均值 `shift(1).rolling(24).mean()`。类别集合预先固定；没有用全数据学习编码。目标、滚动均值和滞后均以目标小时对齐；最初 168 小时只作为历史预热，两模型都从共同可用目标开始评估。

按 22,560 个可用目标的时间顺序，以 `floor(0.70*n)`、`floor(0.85*n)` 为边界划分，不打乱：

| 集合 | 开始目标小时 | 最后目标小时 | 样本数 | 平均计数 |
|---|---|---|---:|---:|
| 训练 | 2018-05-08 00:00 | 2020-02-24 22:00 | 15,791 | 1.9006 |
| 验证 | 2020-02-24 23:00 | 2020-07-14 23:00 | 3,385 | 0.2151 |
| 测试 | 2020-07-15 00:00 | 2020-12-02 23:00 | 3,384 | 0.1785 |

Ridge 的目标函数为平方误差和加 `alpha * ||w||²`，截距不惩罚。对候选 `alpha=[0.1,1,10,100,1000]`，各自只用训练集拟合 `StandardScaler` 与 Ridge，以验证 MAE 最小选取 `alpha=1000`（验证 MAE 0.665812）；该参数位于候选上边界，本阶段不继续扩大搜索，不能称为全局最优。测试集只用于最终评估；选择参数后仍仅在训练集拟合，不把验证集并入训练。

测试期间模型参数与标准化器固定，随着小时推进，两个模型都能使用当时已揭晓的前一小时真实观测。这是逐小时滚动一步评估，不是固定起点的多步预测。假设没有数据上报延迟；如实际存在延迟，需要增加可用数据的滞后。

## 结果与合理性

| 模型 | MAE（次/小时） | RMSE（次/小时） | 负预测数 | 预测范围 |
|---|---:|---:|---:|---|
| Seasonal Naive，24h 周期 | 0.278664 | 0.713141 | 0 | 0—10 |
| Ridge，alpha=1000 | 0.670978 | 0.990752 | 1,233 | −0.914730—3.590471 |

MAE 是平均绝对误差；RMSE 是均方误差的平方根，对较大的误差更敏感。所有指标使用未截断、未四舍五入的预测，测试目标完全相同；不把负数默默改为零。

`error_diagnostics.csv` 中非零小时、零小时及长零区间内外指标仅用于事后解释，不能当作部署时可预先识别的分组。即使只看长零区间以外的 2,369 小时，Seasonal Naive 的 MAE/RMSE 仍为 0.3622/0.7989，Ridge 为 0.7026/1.0275；这不是删除未知停机后的“干净测试集”，也不能消除覆盖不确定性。后续优先核实采集覆盖和时间语义，再考虑非负预测处理、正常运营期评估与其他模型。

## 复现方法

推荐 Python 3.12；本次实际环境 Python 3.12.14。项目依赖固定在 `requirements.txt`，主要库为 NumPy、pandas、scikit-learn 和 Matplotlib。解压交付包，进入包含本 README 的目录，执行：

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe train_baselines.py --data-root .\inputs --output-dir .\rerun
```

如果系统已配置 `python` 和依赖，也可直接运行：

```powershell
python train_baselines.py --data-root "E:\group\ML member1+2\ACN-Data-Static-main" --output-dir .\rerun
```

无需联网获取数据，`inputs` 已包含原样复制的前两阶段 7 个产出文件，不含大型原始压缩时序库。代码只需其中 6 个 CSV；原图随包保留供参考。使用 `--output-dir .\rerun` 可避免覆盖本次交付结果。依赖安装需要可用的 Python 包源；不同底层数学库的浮点数末位可能略有差别。

运行后生成 `model_results.csv`、`predictions.csv`、`model_comparison.png`、`validation_results.csv`、`error_diagnostics.csv`、`monthly_quality_summary.csv` 和 `data_audit.json`。数据缺失、非法数值、重复小时、小时断档、汇总不匹配会报错，不会自行编造或填补数据。`data_audit.json` 保存输入 SHA-256、字段、缺失情况、版本、特征与划分信息。

`predictions.csv` 的 `forecast_origin_last_observed_hour` 是最后已完成小时的起点，`forecast_issued_at` 是实际发出时刻，`target_hour` 是目标小时起点，`target_end` 是目标区间结束；`actual` 是真实计数，`seasonal_naive` 与 `ridge` 是原始预测，最后一列为仅供诊断的事后零区间标记。

已独立检查未来目标扰动不会改变此前特征、lag/rolling 索引正确、预测目标连续一致；从保存的预测独立复算 MAE/RMSE，并用 NumPy 正规方程重算 Ridge，误差在 1e-9 容差内。模型对比图已目视检查。
